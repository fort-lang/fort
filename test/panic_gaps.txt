# Each line is `<path> "<text>"`: the module and the whole text of one `panic` call.
# A listed site has no test and no declaration. tools/panic_coverage.py fails for a site
# with no test that this list does not name, so a new site needs a test or a declaration.
# Remove a line in the commit that adds a test of its site or declares the site unreachable.
# The tool fails for a line that names a tested site, a declared site or no site.
# The comment lines above each group or entry give the reason that the site stays.

# These sites need a span or a view whose length passes its storage. Two forms make one.
# `p[lo..hi]` on a pointer makes a view with no runtime check (D6.9). A pointer cast (D3.14)
# and a same-size reinterpretation (D10.7) can write the pointer or the length of an `own`
# span, such as `cast(&tt.nodes, raw mut*)->len = n`.
# D6.9 and D10.7 make such a view undefined behavior, so no test forges a length or a pointer.
# The 19 reserve guards double the length of an `own` span: a forged length reaches each one.
