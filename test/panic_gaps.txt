# The panic sites that have no test today (tools/panic_coverage.py).
#
# Each line is `<path> "<text>"`: the module and the whole text of one `panic` call.
# A listed site has no test and no declaration. tools/panic_coverage.py fails for a site
# with no test that this list does not name, so a new site needs a test or a declaration.
# Remove a line in the commit that adds a test of its site or declares the site unreachable.
# The tool fails for a line that names a tested site, a declared site or no site.
# The comment lines above each group or entry give the reason that the site stays.

# Four sites need more memory or more steps than a test can use, but a caller with that
# memory and time can reach them. The sizes are sizeof on Darwin arm64.

# 2^32 + 1 owned modules of 152 bytes and their pointers: about 640 GiB.
src/fort/ownership_source.ft "ownership_source: file key overflow"
# An order of 2^32 + 1 module pointers: 32 GiB.
src/fort/ownership_source.ft "ownership_source: module key overflow"
# 2^32 reads in one statement. read_at walks the earlier reads again on each call, so the
# loop takes more than 2^63 steps.
src/fort/ownership_source_live.ft "ownership_source_live: read count overflow"
# 2^64 - 1 reads and writes: more than 2^32 statements of 288 bytes, and 2^64 steps.
src/fort/ownership_source_live.ft "ownership_source_live: write count overflow"

# These sites need a span or a view whose length passes its storage, or many spans that
# share one array. Two forms make one. `p[lo..hi]` on a pointer makes a view with no runtime
# check (D6.9). A pointer cast (D3.14) and a same-size reinterpretation (D10.7) can write the
# pointer or the length of an `own` span, such as `cast(&tt.nodes, raw mut*)->len = n`.
# D6.9 and D10.7 leave the extent to the ownership proof, which runs by default only after
# the ownership series, so no test forges a length or a pointer.
# The 18 reserve guards double the length of an `own` span: a forged length reaches each one.
# fir.loan_count needs 2^32 loan statements: forged blocks can share one statement array.
# ownership_events.clone needs note texts whose total length passes 2^64: two notes with
# `cast(p[0..n], string)` reach it. ownership_join and ownership_state.history need a view of
# at least 2^63 histories of 192 bytes.
