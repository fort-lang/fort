# Known false accepts of one ownership solver alone (D17.14, D17.18).
#
# test/ownership_driver_test.py runs test/ownership/solvers_alone.ft over 156 faulty bodies: the
# faulty body of each of the 37 reject cases of test/ownership/qualification/manifest.json and
# the 119 bodies of test/ownership/solvers/faulty.json. A body is faulty because its source has
# the expected error: the error line of a reject case, or the faulty.json entry of a probe. A
# solver that proves a faulty body gives a false accept.
#
# An entry is `<file>:<body> <solver> # <class>`. The file is relative to the repository root.
# The solver is `summary` or `heap`. A proved faulty body outside this list fails the run. A
# listed entry that no longer proves also fails the run: delete it in the commit that fixes it.
# A list with more entries than the bound line below fails the run. Lower the bound in the
# commit that deletes an entry, and never raise it. The empty list is the goal.
#
# The bound rose from 5 to 16 on 2026-10-11 by a ruling of the user. The 11 entries of classes F,
# G and H existed on main before that ruling. The bitwise `not` rule deleted the 2 class H entries.
# The D10.7 caller requirement deleted the 5 class E entries. The frame rule deleted the 2 class F
# entries. These changes lowered the bound to 7. On 2026-10-11, the user added 2 class I entries
# and 3 class K and L entries. The bound became 12. The escaped-address summary deleted the 2
# class I entries and lowered the bound to 10. The cast storage rule deleted the 7 class G entries
# and lowered the bound to 3. The class K and L callees have complete proofs. A later change can
# extend the summary write footprint.
#
# at most 3 entries
#
# Classes A, B, D, E, F, G, H and I have no entries. Only an established fact removes a path. A
# call forgets each fact that a callee can write through an address of a local. An escaped-address
# summary forgets owner facts that a retained address can change. A dereference adds a D10.7 caller
# requirement. A bitwise `not` uses the width of its type.
# G  A pointer of another pointee type reads no storage fact. A store through it forgets each
#    fact of the base storage. No class G entry remains.
# K  A complete callee writes caller storage through a global. The frame of a call does not
#    reach the storage that a parameter designates, and the summary records no store through a
#    global, so the caller keeps the old value of that storage.
# L  A complete callee writes through a pointer leaf of a by-value aggregate. The graft applies
#    no store through such a leaf, so the caller keeps the old value of the storage that the
#    leaf designates.

# K: a complete callee writes caller storage through a global.
test/ownership/probes/frame_f4_footprint.ft:caller_kept heap # K
test/ownership/probes/frame_f4_footprint.ft:caller_local heap # K
