# Known false accepts of one ownership solver alone (D17.14, D17.18).
#
# test/ownership_driver_test.py runs test/ownership/solvers_alone.ft over 100 faulty bodies: the
# faulty body of each of the 37 reject cases of test/ownership/qualification/manifest.json and
# the 63 bodies of test/ownership/solvers/faulty.json. A body is faulty because its source has
# the expected error: the error line of a reject case, or the faulty.json entry of a probe. A
# solver that proves a faulty body gives a false accept.
#
# An entry is `<file>:<body> <solver> # <class>`. The file is relative to the repository root.
# The solver is `summary` or `heap`. A proved faulty body outside this list fails the run. A
# listed entry that no longer proves also fails the run: delete it in the commit that fixes it.
# A list with more entries than the bound line below fails the run. Lower the bound in the
# commit that deletes an entry, and never raise it. The empty list is the goal.
#
# The bound rose from 5 to 16 on 2026-10-11 by a ruling of the user: merge the rule that only an
# established fact removes a path with these entries in the ledger, and fix the 3 classes in 3
# small later changes. The 11 entries of classes F, G and H were false accepts on main before
# that rule too; its review found them. Each later change lowers the bound.
#
# at most 16 entries
#
# Classes (the earlier classes A, B and D, and a known scalar that a callee writes, have no entry
# left: only an established fact removes a path, D17.18):
# E  No D10.7 caller requirement. A callee dereferences an empty owner of the caller, and no
#    requirement of the caller fails: check_required (src/fort/ownership_heap.ft) reads only

# F  A fact of a local whose address escaped survives a call. forget_scalars forgets only the
#    value of a scalar local; a pointer local whose address an earlier call kept keeps its root
#    fact, and a later call that writes it through a global or an extern changes nothing.
# G  A cast store loses or widens a write. A cast that changes the pointee type keeps the
#    address: a store to a field that has no slot is lost, and a narrow store replaces the
#    whole slot of a wider local or an owner.
# H  `~x` keeps the number of x. rv_not flips the truth of a scalar and keeps `numbered`.
