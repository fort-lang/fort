# listed entry that no longer proves also fails the run: delete it in the commit that fixes it.

# commit that deletes an entry, and never raise it. The empty list is the goal.
#

# A  The address of an assumed cell reads as nonnull. `&n->v` gives no fact about `n`, but the

#    has `returns` false, and each caller path through the call goes.
# D  An unfold-made nonnull is grafted or contradicted. The exit state of the callee says
#    nonnull on each returning path, and the graft makes the caller root nonnull.
# E  No D10.7 caller requirement. A callee dereferences an empty owner of the caller, and no
#    requirement of the caller fails: check_required (src/fort/ownership_heap.ft) reads only
#    require_null. 062 and 063 are the root case; round8_d1 and round8_d2 are the field case.
