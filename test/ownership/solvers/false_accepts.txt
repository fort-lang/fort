# Known false accepts of one ownership solver alone (D17.14, D17.18).
#
# test/ownership_driver_test.py runs test/ownership/solvers_alone.ft over 347 faulty bodies: the
# faulty body of each of the 37 reject cases of test/ownership/qualification/manifest.json and
# the 310 bodies of test/ownership/solvers/faulty.json. A body is faulty because its source has
# the expected error: the error line of a reject case, or the faulty.json entry of a probe. A
# solver that proves a faulty body gives a false accept.
#
# An entry is `<file>:<body> <solver> # <class>`. The file is relative to the repository root.
# The solver is `summary` or `heap`. A proved faulty body outside this list fails the run. A
# listed entry that no longer proves also fails the run: delete it in the commit that fixes it.
# A list with more entries than the bound line below fails the run. Lower the bound in the
# commit that deletes an entry, and never raise it. The empty list is the goal.
#
# The bound rose from 5 to 16 on 2026-10-11 by a ruling of the user. The 11 entries of classes F,
# G and H existed on main before that ruling. The bitwise `not` rule deleted the 2 class H entries.
# The D10.7 caller requirement deleted the 5 class E entries. The frame rule deleted the 2 class F
# entries. These changes lowered the bound to 7. On 2026-10-11, the user added 2 class I entries
# and 3 class K and L entries. The bound became 12. The escaped-address summary deleted the 2
# class I entries and lowered the bound to 10. The cast storage rule deleted the 7 class G entries
# and lowered the bound to 3. The summary write footprint deleted the 3 class K and L entries and
# lowered the bound to 0. On 2026-10-16 the user added the 12 class N entries of the review_s*
# probes and raised the bound to 12. The summary solver fails 11 of them, and 1 stays unproved.
# On 2026-10-15 the user ruled that the ledger takes the 6 class M entries. They reached main
# after class N, and the bound became 18. A later change fixes the heap rule of class M. The
# copied-leaf rule of the heap call transfer deleted the 12 class N entries and lowered the
# bound to 6. On 2026-10-16 the user ruled that the ledger takes the 3 class Q entries of
# test/ownership/probes/copied_references.ft, for a later change, and the bound became 9. The
# summary solver fails 2 of them, and 1 stays unproved. On 2026-10-17 a coordinator ruling, by
# a delegation of the user, added the 3 class P entries of the full-slice and span-header
# probes. The heap solver alone proved them on 3b0fca76 already. The bound became 12. The copy
# rule of the heap scalar operand and of the heap assignment deleted the 3 class Q entries. A
# call of a fort callee without a proof now gives incomplete proof in the caller. Each class M
# caller calls such a callee, so that rule deleted the 6 class M entries. The heap rule of class
# M, a read through a loaded reference, still has no fix. The bound became 3. On 2026-10-16 the
# user ruled that the ledger takes the faulty bodies of the base probes that the heap solver
# alone proves, in classes O and P. A body joins faulty.json only when the summary solver and
# the calls_heap row prove it 0 times. With the base rule of the summary solver, the 84 faulty
# bodies of the base probes joined: 8 entries of class O and 8 of class P. The bound became 19.
#
# at most 19 entries
#
# Classes A, B, D, E, F, G, H, I, K, L, M, N and Q have no entries. Only an established fact
# removes a path. A call forgets each fact that a callee can write through an address or a
# write footprint. A dereference adds a D10.7 caller requirement. A bitwise `not` uses the width
# of its type.
# G  A pointer of another pointee type reads no storage fact. A store through it forgets each
#    fact of the base storage. No class G entry remains.
# I  A callee changes an owner through an escaped local address. A callee that fails its own
#    proof can change storage through an address. The summary now records this effect.
# K  A complete callee can write through a global-held pointer. The summary now records this
#    footprint and forgets reachable caller storage.
# L  A complete callee can write through a by-value pointer leaf. The summary now records this
#    footprint and forgets the storage that the matching actual leaf designates.
# M  A loaded-source caller whose heap facts the callee changes. The caller passes storage that
#    holds a reference, and the callee loads the reference and reads through it. A release
#    before the call empties the referent: in the caller, in a callee that stores the
#    reference, or through a global. Each such callee has no proof, and a call of a callee
#    without a proof gives incomplete proof. No class M entry remains.
# N  A dangling borrowed leaf of a copied aggregate call argument. The caller copies a by-value
#    aggregate whose reference leaf names released storage. The heap call transfer now checks
#    each borrowed leaf of an aggregate argument against the state at the call (D17.14).
# O  Two inputs name one storage, and the heap solver keeps a stale fact (D17.4). A store
#    or a release through one formal does not change the fact that it keeps for the other.
# P  A read of caller storage after its release or move. The body moves the owner out of a
#    caller field and then slices that field or copies its pointer field, or it reads through
#    a base after it releases, moves or clears that base. The heap solver alone proves each
#    body. The summary solver and the calls_heap row prove none.
# Q  A dangling reference copied as a scalar argument, a scalar or an aggregate assignment.
#    D17.14 makes each copy a use. The heap solver now checks the copy of a borrowed reference
#    in a scalar call argument, an assignment, a struct literal field and a reference element of
#    an array literal. No class Q entry remains.
