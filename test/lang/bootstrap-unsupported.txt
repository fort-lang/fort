# Tests that use features the C bootstrap compiler deliberately lacks: floats
# (f32, f64, float literals), the nested array and span levels of D3.6,
# do { } while and ?:. Function pointers are in the bootstrap's subset (D3.10).
# Path prefixes, relative to test/lang.
#
# Each must be rejected: exit 1, with at least one diagnostic, and at least one
# of them either containing "not supported by the bootstrap compiler" or
# standing in a file of the test itself (toolchain.md 7.3, T-131). Every entry
# below takes the first shape today. The second shape is for the feature this
# compiler never learned to name: it compiles the pinned tree of
# tools/bootstrap.ref and not HEAD, so a form added after that pin reaches it
# as an ordinary syntax error.
#
# This is stage1's list. stage2 is judged by test/lang/unsupported-stage2.txt,
# which run_tests.py takes as --unsupported and which is shorter: src/fort
# implements the nested levels (T-043), `do { } while` and `?:` (D6.6, D7.5,
# T-044) and floats (D2.6, D3.1, T-041), and src/bootstrap implements none of
# them. Every float test here is one stage2 runs and passes.
#
# A test that imports std.math is here whatever it uses of the module: the
# module holds f64 functions and `?:`, and stage1 refuses the whole import
# closure of a program (T-042). run/stdlib/096 names no float and is listed
# for that reason.
