# Tests the compiler cannot pass yet (D14.4): a listed test that fails is an
# expected failure, a listed test that passes fails the run, so an entry
# leaves this list in the commit that makes its test pass. Entries are path
# prefixes relative to test/lang, so a directory covers everything under it.
#
# After T-017 the compiler produces a running program for the scalar half of
# the language with its control flow and its calls: literals, locals,
# arithmetic with its checks, comparisons, the print family, assert and panic,
# calls of every form including calls through a function pointer, structs by
# value, fixed arrays, `if`, `while`, every `for` form and `break` and
# `continue`. What is left below waits for the tickets after it: switch
# (T-020), spans, strings and `new` (T-021), ownership (T-022), deferred
# statements (T-023) and module-level data (T-024), plus the `fail` tests
# whose error is an ownership rule of D17. An entry names the ticket that
# unblocks it, not the feature its file is named after:
# run/functions/003_noreturn.ft waits for the spans of T-021, not for
# `noreturn`, which already works.
