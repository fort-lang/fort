# Tests the compiler cannot pass yet (D14.4): a listed test that fails is an
# expected failure, a listed test that passes fails the run, so an entry
# leaves this list in the commit that makes its test pass. Entries are path
# prefixes relative to test/lang, so a directory covers everything under it.
#
# After T-013 (modules and scopes) the compiler lexes, parses and resolves the
# import closure, so the lexical, syntax and module diagnostics are the ones
# that work; everything below waits for the checker (T-014), the emitter
# (T-015) and the tickets after them, which is why the list is mostly files
# rather than directories. Five of the entries wait for the error recovery of
# T-057 instead: fail/mutability/004 and 006 and fail/ownership/009 and 022
# carry two syntax errors on separate lines and fail/ownership/010 carries
# three, of which D14.2 as written reports one. fail/ownership/027 is neither:
# the parser reports one diagnostic on the annotated line, but picks the
# statement message ("expected an assignment, an increment or a call, found
# '*'") for `node* mut own p`, which is message selection and belongs to the
# parser (T-012).
